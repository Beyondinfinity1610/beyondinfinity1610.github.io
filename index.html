Seizure detection from a wearable

Four signals in.

A behind-the-ear wearable records brain, heart, muscle and movement at the same time. My first seizure detector fused all four, end to end. Its score stalled at ~0.57 AUROC.

  • Brain EEG
  • Heart ECG
  • Muscle EMG
  • Movement accelerometer

Three of them did nothing.

Instead of tuning it, I looked inside. The model only read 2 s of each 17 s window. The fusion weights on heart, muscle and movement were 0.000: exactly zero, not small.

More features entered. More signal did not leave.

So I rebuilt it, one step at a time.

I removed what did not contribute, supplied evidence that did, and kept two failures on the record: +0.316 AUROC across the ladder. Then I scored it on patients it had never seen.

AUROC on patients never seen in training

0.82695% CI [0.782–0.860]

  • SeizeIT2 official patient-level split
  • continuous recordings
  • interval from a bootstrap over patients
  • Floor: 0.5 (chance)

It finds 67.4% of seizures at 10 false alarms/hour. That is a lot of false alarms, so this is a candidate-event aid, not an alarm.

ADHD classification from EEG, ongoing

A great number. Then the audit.

Is high accuracy on EEG-based ADHD classification trustworthy? My own graph network said it was. Run the checks I ran, one at a time.

Accuracy, my earlier internal headline

92.19%

Set aside. Selection effect: ~15 points

AUC, higher is better

Zoomed in
0.656 Recording length only
0.884 Graph network
0.896 Linear, 25 features
0.905 ± 0.013 Published comparator
0.9334 ± 0.0149 Rebuild

  1. On the test fold. Choosing it without the test fold costs about ~15 points. The headline is set aside.

  2. Recording length alone, with no EEG at all, reaches AUC 0.656. On this benchmark that is the honest floor, not chance.

  3. A linear model on 25 features scores AUC 0.896. My graph network: 0.884. The simple model wins.

  4. Subject-independent, five folds, ten seeds: AUC 0.9334 ± 0.0149. The strongest published comparator with a verifiable protocol: 0.905 ± 0.013.
